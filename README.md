## 中文

### 整合包介绍

**钻石大陆加豪版**是一款中等难度的科技向整合包。按玩法类型划分，本整合包可归为类空岛整合包；但其实际开局环境并非传统虚空岛屿，而是超平坦钻石矿大陆。

本整合包以**格雷科技现代版**为主要流程，并穿插少量其他模组内容，用于辅助玩家逐步建立工业体系。此外，本包提供可选魔法线，可作为主线推进过程中的补充内容。

整合包内包含少量剧情文本；剧情内容为补充性质，不影响主要流程推进。

本整合包设计了多条新增产线，旨在提供新的流程规划、资源处理与自动化挑战。

### 注意事项

本整合包为重度魔改整合包，包含大量重新设计或调整后的流程内容。

目前，本包仍处于早期开发阶段，可能存在数值平衡不完善、流程阻塞等问题。如发现相关问题，请通过 Issues 页面反馈。

## English

### About

**Diamond Continent — Plus&Plus Edition** is a medium-difficulty technology-focused modpack. In terms of gameplay classification, it can be considered a skyblock-like modpack; however, its starting environment is not a traditional void island, but a superflat continent made of diamond ore.

The main progression is built around **GregTech Modern**, with a small number of progression elements from other mods included to support the development of an industrial system. The pack also provides an optional magic progression line as supplementary content alongside the main progression.

The modpack contains a small amount of story text. This content is supplementary and is not required for progression.

Several new production lines have been designed for this pack, providing additional challenges in process planning, resource handling, and automation.

### Notes

This is a heavily customized modpack, with many progression steps redesigned or adjusted.

The pack is currently in an early stage of development. Balance issues, progression blockers, or other problems may occur. If any issues are found, please report them through the Issues page.
